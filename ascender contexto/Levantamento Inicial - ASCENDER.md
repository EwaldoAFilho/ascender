# Levantamento Inicial - ASCENDER

## Objetivo

Registrar as perguntas e pontos de descoberta necessarios antes de definir o sistema, os dashboards e a arquitetura.

## Perguntas de Negocio

- Qual area da ASCENDER sera acompanhada primeiro?
- Qual problema precisa ser resolvido ou monitorado?
- Quais decisoes o dashboard deve apoiar?
- Quem vai usar o dashboard no dia a dia?
- O uso sera operacional, gerencial ou executivo?
- Quais indicadores ja sao acompanhados hoje?
- O acompanhamento atual e feito em planilha, sistema, relatorio ou manualmente?

## Perguntas Sobre Dados

- Quais sistemas armazenam os dados?
- Existem APIs disponiveis?
- Existem bancos de dados acessiveis?
- Os dados estao em planilhas?
- Qual e a periodicidade de atualizacao necessaria?
- Ha historico suficiente para analise?
- Existem regras de permissao ou sigilo?

## Perguntas Sobre Produto

- O projeto deve comecar apenas como dashboard?
- O dashboard precisa evoluir para sistema com cadastro, workflow ou automacoes?
- Sera necessario login por usuario?
- Havera perfis de acesso?
- O sistema sera interno ou acessado por clientes/parceiros?
- A solucao precisa funcionar em mobile?

## Saida Esperada da Descoberta

- problema priorizado
- lista inicial de indicadores
- fontes de dados mapeadas
- usuarios e perfis identificados
- periodicidade de atualizacao definida
- primeiro escopo de dashboard aprovado
- direcao tecnica inicial registrada
